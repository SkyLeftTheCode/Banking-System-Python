# Python ATM System

**Short Description:**  
This is a console-based ATM system built with Python. I created it to practice Python programming, OOP concepts, and basic banking operations.

## Features
- Create a new account with account number and PIN.  
- Login with account number and PIN.  
- Check account balance.  
- Deposit money.  
- Withdraw money with validation.  
- Exit the system safely.  

## How to Use
1. Run `main.py`.  
2. Select an option from the menu (1–5).  
3. If you don’t have an account, choose option **4** to create one.  
4. Use your account number and PIN to login.  
5. Perform balance checks, deposits, or withdrawals.  

## Built With
- Python 3  
- Classes (`Account`, `Bank`, `Main`)  
- Dictionary for storing accounts
